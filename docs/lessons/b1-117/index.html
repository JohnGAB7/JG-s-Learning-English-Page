So et such

« So » et « such » renforcent un adjectif ou un nom, comme « si », « tellement » ou « tel » en français : « It was so hot! », « It was such a hot day! ». Ils servent aussi à exprimer une conséquence avec « that » : « so tired that I fell asleep ». La règle de construction est simple, mais les francophones la confondent souvent.

À la fin de cette leçon, tu sauras :
  • Utiliser so + adjectif / adverbe et such (a / an) + (adjectif) + nom.
  • Choisir entre so many / so much / so few / so little et such a lot of.
  • Exprimer une conséquence avec so … that et such … that.
  • Distinguer so / such de very et éviter « so a » ou « such beautiful ».

So + adjectif ou adverbe

« So » se place devant un adjectif seul (sans nom après) ou devant un adverbe. Il est plus expressif que « very » : il traduit souvent une émotion ou une réaction (surprise, admiration, agacement).

Différence avec very : « very » donne une simple information (« The film was very long »), « so » ajoute une émotion ou appelle une conséquence (« The film was so long! I nearly fell asleep »).

  • The view from Mount Cameroon is so beautiful!
    La vue depuis le mont Cameroun est tellement belle !
  • You speak so quickly — I can't follow you.
    Tu parles si vite, je n'arrive pas à te suivre (so + adverbe).
  • I'm so happy you came!
    Je suis tellement content que tu sois venu !

Such + (a / an) + adjectif + nom

« Such » se place devant un groupe nominal. Avec un nom dénombrable singulier, on met « a / an » APRÈS such : such a + (adjectif) + nom. Avec un nom pluriel ou indénombrable, pas d'article : such + (adjectif) + nom.

Retenir la symétrie : « so + adjectif » quand l'adjectif est seul ; « such + nom » dès qu'il y a un nom.

StructureExempleTraduction
so + adjectifThe day was so hot.La journée était si chaude.
such a + adjectif + nom singulierIt was such a hot day.C'était une journée si chaude.
such + adjectif + nom plurielThey are such kind people.Ce sont des gens si gentils.
such + adjectif + nom indénombrableWe had such good weather.Nous avons eu un si beau temps.
such a + nom (sans adjectif)He's such a liar!C'est un tel menteur !

So many, so much, such a lot of

Devant une quantité, on utilise so + many / much / few / little : so many people (dénombrable), so much traffic (indénombrable), so few chairs, so little time.

« Such a lot of » est l'équivalent familier pour les deux types de noms : such a lot of work, such a lot of problems. On ne dit pas « such many » ni « so a lot of ».

  • There were so many people at the concert in Abidjan!
    Il y avait tellement de monde au concert à Abidjan !
  • I have so much work this week.
    J'ai tellement de travail cette semaine.
  • We had such a lot of fun at the wedding.
    On s'est tellement amusés au mariage.

La conséquence : so … that / such … that

On ajoute « that » + proposition pour exprimer la conséquence : « tellement … que ». À l'oral, « that » est souvent omis : « I was so tired I fell asleep on the bus ».

Les mêmes règles de construction s'appliquent : so + adjectif / adverbe / quantité + that ; such (a) + nom + that.

  • The exam was so difficult that half the class failed.
    L'examen était si difficile que la moitié de la classe a échoué.
  • It was such a good film that I watched it twice.
    C'était un si bon film que je l'ai regardé deux fois.
  • She drove so fast that she got a fine.
    Elle a conduit si vite qu'elle a eu une amende.
  • There was so much noise that we couldn't talk.
    Il y avait tellement de bruit qu'on ne pouvait pas parler.

Autres emplois et registre

« So » est très fréquent à l'oral, surtout pour exprimer des émotions : « I'm so sorry », « Thank you so much », « It's so nice to see you ». À l'écrit formel, on préfère souvent extremely, very, particularly.

« Such » peut aussi signifier « de ce type, pareil » : « I've never seen such a thing » (je n'ai jamais vu une chose pareille), « such as » = « comme, par exemple » : « fruit such as mangoes and papayas ».

Dans une question avec un adjectif, on peut dire « Why are you so angry? » ; « how » sert pour l'exclamation : « How beautiful! » = « It's so beautiful! ».

  • Thank you so much for your help.
    Merci infiniment pour ton aide.
  • The shop sells tropical fruit such as mangoes and pineapples.
    Le magasin vend des fruits tropicaux comme les mangues et les ananas.

La formule

so + adjectif / adverbe · such (a / an) + (adjectif) + nom · so many / much + nom · … (that) + conséquence

Prononciation

Pronunciation Lab

  • « so » est souvent allongé et accentué pour l'émotion : It was SOOO good! /səʊ/ (GB).
  • « such » se prononce /sʌtʃ/ : u court comme dans « cup », finale /tʃ/ comme dans « match ».
  • Dans « such a », les mots se lient : /ˈsʌtʃ ə/, presque « sutcha ».
  • Dans « so … that », « that » est faible : /ðət/ ; l'accent porte sur so et sur l'adjectif : so TIRED that…

Les erreurs fréquentes

À éviterÀ direPourquoi
✗ It was so a beautiful day.✓ It was such a beautiful day.Avec un nom : such a, pas so a.
✗ They are so nice people.✓ They are such nice people.Adjectif + nom pluriel : such.
✗ She's such kind.✓ She's so kind.Adjectif seul : so.
✗ It was a such good idea.✓ It was such a good idea.L'article se place après such.
✗ There were such many cars.✓ There were so many cars.Quantité : so many / so much.
✗ I was so tired as I fell asleep.✓ I was so tired (that) I fell asleep.La conséquence s'introduit avec that (ou sans mot).
✗ We had such a good weather.✓ We had such good weather.weather est indénombrable : pas de a.

En situation

Listening Studio

Kevin rentre d'un week-end au festival de jazz de Montréal et le raconte à sa collègue Aïcha.

Aïcha

So, how was the jazz festival?
Alors, c'était comment, le festival de jazz ?

Kevin

Amazing! There were so many people that we could hardly move.
Génial ! Il y avait tellement de monde qu'on pouvait à peine bouger.

Aïcha

And the music?
Et la musique ?

Kevin

It was such good music. The last band was so talented that everyone was dancing.
C'était de si bonne musique. Le dernier groupe était si talentueux que tout le monde dansait.

Aïcha

Lucky you! Was the weather OK?
Quelle chance ! Il a fait beau ?

Kevin

We had such a hot weekend — 32 degrees! And the concerts finished so late.
On a eu un week-end si chaud, 32 degrés ! Et les concerts finissaient tellement tard.

Aïcha

You must be so tired.
Tu dois être tellement fatigué.

Kevin

I am! I had such a lot of fun, but I need a holiday after my holiday!
Oui ! Je me suis tellement amusé, mais j'ai besoin de vacances après mes vacances !

Exercices

Writing Workshop

Du plus simple au plus difficile. Réponds sans regarder la leçon, puis vérifie chaque exercice.

1. So ou such ?

Complète avec so ou such (a / an si nécessaire).

  1. The soup is ___ hot that I can't eat it.
  2. It was ___ interesting book.
  3. They are ___ friendly neighbours.
  4. Why are you ___ angry?
  5. We had ___ bad luck on our trip.
  6. He runs ___ fast!
  7. It's ___ beautiful city.
Voir le corrigé
  1. so
  2. such an
  3. such
  4. so
  5. such
  6. so
  7. such a

2. So many, so much, such a lot of

Complète avec so many, so much ou such a lot of (parfois deux réponses).

  1. There's ___ traffic in Lagos.
  2. I've got ___ emails to answer.
  3. She spent ___ money on clothes.
  4. There were ___ mistakes in the report.
Voir le corrigé
  1. so much / such a lot of
  2. so many / such a lot of
  3. so much / such a lot of
  4. so many / such a lot of

3. Relier avec so / such … that

Relie les deux phrases avec so … that ou such … that.

  1. The film was boring. I fell asleep.
  2. It was a long queue. We left.
  3. She was nervous. She couldn't speak.
  4. They are good friends. They talk every day.
Voir le corrigé
  1. The film was so boring that I fell asleep.
  2. It was such a long queue that we left.
  3. She was so nervous that she couldn't speak.
  4. They are such good friends that they talk every day.

4. Corriger l'erreur

Chaque phrase contient une erreur. Réécris-la correctement.

  1. It was so a nice evening.
  2. He's such rude!
  3. We had such a terrible weather.
  4. There were such many people.
Voir le corrigé
  1. It was such a nice evening.
  2. He's so rude!
  3. We had such terrible weather.
  4. There were so many people.

5. Traduire

Traduis en anglais.

  1. C'est une si jolie maison !
  2. J'étais tellement fatigué que je suis rentré tôt.
  3. Il y avait tellement de bruit !
Voir le corrigé
  1. It's such a nice / pretty house!
  2. I was so tired that I went home early.
  3. There was so much noise!

6. À toi

Raconte un événement marquant (fête, voyage, concert, match) en cinq phrases avec so, such et au moins deux conséquences avec that.

  1. Exemple de réponse
Voir le corrigé
  1. Last year I went to my cousin's wedding in Bafoussam. It was such a big wedding — there were more than 500 guests! The food was so delicious that I ate three plates. The music was so loud that I couldn't hear my phone. It was such a wonderful day.
À retenir
  • so + adjectif / adverbe seul (so hot, so quickly).
  • such + (a / an) + (adjectif) + nom (such a hot day, such kind people, such good weather).
  • so many / so much / so few / so little + nom ; such a lot of + nom.
  • Conséquence : so / such … (that) + proposition.
  • Jamais « so a » ni « a such » ; pas de a avec un indénombrable (such good weather).
