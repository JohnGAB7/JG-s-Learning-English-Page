Le zéro conditionnel (vérités générales)

Le zéro conditionnel (If you heat ice, it melts) exprime ce qui arrive toujours quand une condition est remplie : lois de la nature, habitudes, règles, modes d'emploi. Il utilise le présent simple dans les deux parties.

⏱ 30–45 min✎ Rédigé par JG◎ Niveau B1

Envie d’immersion ? This lesson in English →

À la fin de cette leçon, tu sauras :
  • Construire le zéro conditionnel avec if / when + présent simple, présent simple.
  • L'utiliser pour les faits scientifiques, les habitudes, les règles et les consignes.
  • Le distinguer du premier conditionnel (situation précise et future).
  • Utiliser l'impératif et les modaux dans la partie résultat pour les consignes.

La structure

Condition : if (ou when, whenever) + présent simple. Résultat : présent simple. Les deux parties sont au présent, parce que ce n'est pas un événement unique : c'est vrai à chaque fois.

If peut presque toujours être remplacé par when ou whenever sans changer le sens : « If / When you mix red and blue, you get purple. » C'est le test le plus simple pour reconnaître un zéro conditionnel.

Condition (if / when + présent)Résultat (présent)
If you heat water to 100 °C,it boils.
When it rains,the roads get slippery.
If I drink coffee after 6 p.m.,I can't sleep.
If you don't water plants,they die.

Les vérités générales et scientifiques

C'est l'usage le plus connu : les lois de la nature et les faits toujours vrais. On l'utilise beaucoup dans les cours de sciences, de géographie, d'économie.

En français, on utilise aussi le présent dans les deux parties (« Si on chauffe la glace, elle fond »), donc la structure est facile ; le piège est surtout d'utiliser will par erreur.

  • If you heat ice, it melts.
    Si on chauffe de la glace, elle fond.
  • Plants die if they don't get enough light.
    Les plantes meurent si elles ne reçoivent pas assez de lumière.
  • When demand rises, prices go up.
    Quand la demande augmente, les prix montent.

Les habitudes et les réactions personnelles

On l'emploie aussi pour parler de ce qui nous arrive toujours, de nos habitudes ou de nos réactions : « If I'm stressed, I eat chocolate. » Ce n'est pas une loi universelle, mais c'est vrai pour moi à chaque fois.

Pour une habitude passée, on met les deux verbes au prétérit : « When I was a child, if it rained, we stayed inside and played cards. »

  • If I don't have breakfast, I feel tired all morning.
    Habitude : chaque fois.
  • My grandmother gets angry if we arrive late.
    Réaction habituelle.
  • When we lived in Garoua, if it was too hot, we slept on the terrace.
    Habitude passée : prétérit des deux côtés.

Règles et modes d'emploi : impératif et modaux

Pour donner une consigne générale, le résultat est souvent à l'impératif : « If the alarm rings, leave the building. » On le trouve sur les affiches, les notices, les règlements.

On peut aussi utiliser un modal (can, must, should) : « If you are under 18, you can't vote. » / « If you feel dizzy, you should sit down. »

ContexteExemple
SécuritéIf there is a fire, don't use the lift.
Mode d'emploiIf the light turns red, press the reset button.
RèglementIf you lose your card, you must pay a fee.
SantéIf you have a fever, drink plenty of water.

Zéro ou premier conditionnel ?

Zéro : vrai à chaque fois, en général (présent + présent). Premier : une situation précise, dans le futur (présent + will).

« If you press this button, the machine stops » (c'est comme ça qu'elle fonctionne, toujours). « If you press this button now, the machine will stop » (là, maintenant, une seule fois).

Signal utile : quand on peut dire « whenever » ou « every time », c'est le zéro conditionnel. Quand il y a tomorrow, tonight, next week, c'est le premier.

  • If you mix oil and water, they don't combine.
    Toujours vrai : zéro.
  • If you mix these colours, your painting will look dark.
    Cette fois-ci, résultat prévu : premier.

La formule

If / When + présent simple, présent simple (If you heat ice, it melts.)

Prononciation

Pronunciation Lab

  • Le -s de la 3e personne est indispensable et s'entend : melts /melts/, boils /bɔɪlz/, rises /ˈraɪzɪz/. Trois prononciations : /s/, /z/, /ɪz/.
  • when /wen/ et if /ɪf/ sont souvent faibles en début de phrase ; l'accent tombe sur le verbe et le nom importants : « If you HEAT ICE, it MELTS. »
  • Intonation : montée à la fin de la condition, descente à la fin du résultat.
  • whenever /wenˈevə/ : accent sur la deuxième syllabe.

Les erreurs fréquentes

À éviterÀ direPourquoi
✗ If you heat the ice, it melts.✓ If you heat ice, it melts.Vérité générale : pas d'article devant un nom indénombrable pris au sens général (le français dit « la glace »).
✗ If water freeze, it become ice.✓ If water freezes, it becomes ice.N'oublie pas le -s de la 3e personne.
✗ When I will be tired, I go to bed.✓ When I'm tired, I go to bed.Jamais will après when / if.
✗ If you will press the button, the door opens.✓ If you press the button, the door opens.Présent simple dans la condition.
✗ If it rains, people are taking umbrellas.✓ If it rains, people take umbrellas.Habitude générale : présent simple, pas présent continu.
✗ If there will be a fire, use the stairs.✓ If there is a fire, use the stairs.Consigne : if + présent, impératif.

En situation

Listening Studio

Une classe de sciences dans un lycée de Liège. Mme Dubois explique une expérience à ses élèves, Théo et Aïcha.

Mme Dubois

What happens if you put salt on ice?
Qu'est-ce qui se passe si on met du sel sur la glace ?

Théo

It melts faster.
Elle fond plus vite.

Mme Dubois

Exactly. That's why the city puts salt on the roads when it snows.
Exactement. C'est pour ça que la ville met du sel sur les routes quand il neige.

Aïcha

And if the temperature is very low, does salt still work?
Et si la température est très basse, le sel marche toujours ?

Mme Dubois

Good question. If it's colder than about minus ten, salt doesn't work very well.
Bonne question. S'il fait plus froid qu'environ moins dix, le sel ne marche pas très bien.

Théo

In Cameroon, my cousins never see snow. If it rains a lot, the roads just get muddy.
Au Cameroun, mes cousins ne voient jamais la neige. S'il pleut beaucoup, les routes deviennent juste boueuses.

Mme Dubois

That's right. Now, safety first: if you spill anything, tell me immediately.
C'est juste. Maintenant, la sécurité d'abord : si vous renversez quelque chose, dites-le-moi tout de suite.

Aïcha

And if we finish early, can we try with sugar?
Et si on finit tôt, on peut essayer avec du sucre ?

Exercices

Writing Workshop

Du plus simple au plus difficile. Réponds sans regarder la leçon, puis vérifie chaque exercice.

1. Associer

Associe les débuts et les fins : a) it turns into steam. b) I get a headache. c) you get green. d) leave the building.

  1. If you mix blue and yellow, …
  2. If water boils, …
  3. If I don't drink enough water, …
  4. If the fire alarm rings, …
Voir le corrigé
  1. c) you get green.
  2. a) it turns into steam.
  3. b) I get a headache.
  4. d) leave the building.

2. Conjuguer

Mets les verbes au présent simple (zéro conditionnel).

  1. If you ___ (drop) a glass, it ___ (break).
  2. When my phone battery ___ (be) low, the screen ___ (get) darker.
  3. If people ___ (not / sleep) enough, they ___ (feel) irritable.
  4. My dog ___ (bark) if someone ___ (ring) the bell.
  5. If you ___ (not / pay) the bill, they ___ (cut) the electricity.
Voir le corrigé
  1. drop … breaks
  2. is … gets
  3. don't sleep … feel
  4. barks … rings
  5. don't pay … cut

3. Zéro ou premier ?

Choisis la bonne forme.

  1. If you heat metal, it (expands / will expand). (toujours)
  2. If you call me tonight, I (tell / will tell) you everything.
  3. When I'm nervous, I (talk / will talk) too much.
  4. If it rains tomorrow, the match (is / will be) cancelled.
Voir le corrigé
  1. expands
  2. will tell
  3. talk
  4. will be

4. Corriger les erreurs

Chaque phrase contient une erreur. Corrige-la.

  1. If you press this button, the machine stop.
  2. When the sun will set, it gets cold in the desert.
  3. If there will be an emergency, call 112.
  4. If my brother is hungry, he is getting angry.
Voir le corrigé
  1. If you press this button, the machine stops.
  2. When the sun sets, it gets cold in the desert.
  3. If there is an emergency, call 112.
  4. If my brother is hungry, he gets angry.

5. Traduire

Traduis en anglais.

  1. Si on chauffe de la glace, elle fond.
  2. Quand je bois du café le soir, je ne dors pas.
  3. Si vous perdez votre ticket, vous devez payer une amende.
  4. Si tu as de la fièvre, bois beaucoup d'eau.
Voir le corrigé
  1. If you heat ice, it melts.
  2. When I drink coffee in the evening, I don't sleep. / I can't sleep.
  3. If you lose your ticket, you must pay a fine.
  4. If you have a fever, drink a lot of water.

6. À toi

Écris 4 phrases au zéro conditionnel : un fait scientifique, une de tes habitudes, une règle de ton école ou de ton travail, et une consigne de sécurité (impératif).

  1. Exemple de réponse
Voir le corrigé
  1. If you freeze water, it turns into ice. If I go to bed late, I feel tired the next day. At my company, if you work on Saturday, you get a day off. If you smell gas, open the windows and leave the house.
À retenir
  • If / When + présent simple, présent simple : ce qui arrive toujours.
  • Usages : lois de la nature, habitudes, règles, modes d'emploi.
  • If peut être remplacé par when / whenever sans changer le sens.
  • Résultat à l'impératif ou avec un modal pour les consignes.
  • Situation précise et future → premier conditionnel (will).
