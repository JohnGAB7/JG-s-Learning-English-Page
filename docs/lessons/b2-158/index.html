Les conditionnels mixtes

« Si j'avais accepté ce poste, je vivrais à Montréal aujourd'hui » ; « S'il était plus organisé, il n'aurait pas raté l'échéance ». La condition et le résultat ne se situent pas toujours au même moment : les conditionnels mixtes combinent les deuxième et troisième conditionnels pour relier le passé et le présent. Ils sont indispensables pour parler de ses choix, de ses regrets et de leurs conséquences.

⏱ 30–45 min✎ Rédigé par JG◎ Niveau B2

Envie d’immersion ? This lesson in English →

À la fin de cette leçon, tu sauras :
  • Relier une condition passée à un résultat présent : If + past perfect, would + base verbale.
  • Relier une caractéristique présente (permanente) à un résultat passé : If + prétérit, would have + participe.
  • Utiliser could, might et les formes progressives dans le résultat.
  • Analyser le moment de la condition et celui du résultat pour choisir la bonne structure.

Rappel : les deux briques de base

Le deuxième conditionnel parle d'une situation irréelle dans le présent ou le futur : If + prétérit, would + base verbale. « If I had more time, I would learn Spanish. »

Le troisième conditionnel parle d'une situation irréelle dans le passé : If + past perfect, would have + participe. « If you had told me, I would have helped. »

Un conditionnel mixte prend la proposition en « if » de l'un et la proposition principale de l'autre, selon le moment réel de chaque partie.

TypeCondition (if)RésultatExemple
2e conditionnelprésent irréel : prétéritprésent : would + baseIf I had a car, I would drive to work.
3e conditionnelpassé irréel : past perfectpassé : would have + participeIf I had left earlier, I would have caught the train.
Mixte Apassé irréel : past perfectprésent : would + baseIf I had left earlier, I would be there now.
Mixte Bprésent irréel : prétéritpassé : would have + participeIf I were more organised, I wouldn't have missed the train.

Mixte A : passé → présent

C'est le plus fréquent. On imagine qu'un événement passé s'est déroulé autrement, et on en mesure la conséquence aujourd'hui.

Les marqueurs « now », « today », « still », « at the moment » dans le résultat sont des indices utiles.

Le français fonctionne de la même façon : « Si j'avais fait médecine, je serais médecin aujourd'hui » (plus-que-parfait + conditionnel présent). La structure anglaise est donc logique pour un francophone ; le piège est surtout d'écrire « would have been » par réflexe.

  • If I had studied medicine, I would be a doctor now.
    Si j'avais fait médecine, je serais médecin aujourd'hui.
  • If she hadn't missed the plane, she would be in Dakar at the moment.
    Elle serait à Dakar en ce moment.
  • If we had bought that flat in 2010, we would be rich today.
    Nous serions riches aujourd'hui.
  • If I hadn't met you, my life would be very different.
    Ma vie serait très différente.

Mixte B : présent (permanent) → passé

La condition porte sur une caractéristique durable, vraie hier comme aujourd'hui (personnalité, compétence, situation), et le résultat sur un événement passé précis.

On utilise le prétérit (souvent « were » pour toutes les personnes dans un style soigné) dans la proposition en if, et would have + participe dans la principale.

Exemple type : « If I spoke Dutch, I would have understood the announcement » : je ne parle pas néerlandais (ni hier ni aujourd'hui), donc je n'ai pas compris l'annonce hier.

  • If he were more patient, he wouldn't have shouted at the children.
    S'il était plus patient, il n'aurait pas crié.
  • If she spoke French, she would have got the job in Lyon.
    Si elle parlait français, elle aurait eu le poste.
  • If I weren't afraid of flying, I would have visited you in Toronto.
    Si je n'avais pas peur de l'avion…
  • If they didn't trust you, they wouldn't have given you the keys.
    S'ils n'avaient pas confiance en toi…

Variantes : could, might, formes progressives

Dans le résultat, « would » peut être remplacé par « could » (capacité) ou « might » (possibilité) : « If I had learnt to drive, I could apply for this job now. »

Les formes progressives sont fréquentes : « If I hadn't stayed up so late, I wouldn't be feeling so tired » ; « If she hadn't moved to Canada, she would still be living with her parents ».

La condition passée peut aussi avoir une conséquence future : « If he had booked the tickets, we would be flying to Montréal tomorrow. »

  • If I had learnt English as a child, I might be working abroad now.
    might : possibilité.
  • If you had listened to the instructions, you could do the exercise now.
    could : capacité présente.
  • If I hadn't drunk three coffees, I wouldn't be feeling so nervous.
    Résultat progressif.

Méthode : situer chaque partie dans le temps

Avant d'écrire, posez deux questions. 1) La condition est-elle passée (un événement terminé) ou présente (une situation toujours vraie) ? 2) Le résultat concerne-t-il le présent ou le passé ?

Condition passée → past perfect. Condition présente → prétérit. Résultat présent → would + base. Résultat passé → would have + participe.

Comme dans tous les conditionnels, on ne met jamais « would » dans la proposition en if. L'ordre des propositions peut s'inverser ; on met une virgule seulement quand « if » vient en premier.

Situation réelleAnalyseConditionnel mixte
I didn't take the job. I'm unemployed now.passé → présentIf I had taken the job, I wouldn't be unemployed now.
I'm not tall. I wasn't chosen for the team.présent → passéIf I were taller, I would have been chosen for the team.
She lost her passport. She can't travel now.passé → présent (could)If she hadn't lost her passport, she could travel now.

La formule

If + past perfect, would + base (passé → présent) · If + prétérit, would have + participe (présent → passé)

Prononciation

Pronunciation Lab

  • « I'd » peut valoir « I had » ou « I would » : « If I'd known » (had), « I'd be there » (would). Le verbe qui suit permet de distinguer.
  • « would have » se réduit à /wʊdəv/ ou /ˈwʊdə/ à l'oral rapide : « I'd have come » /aɪd əv ˈkʌm/. « wouldn't have » : /ˈwʊdntəv/.
  • « hadn't » /ˈhædnt/ : le t final est souvent à peine prononcé.
  • Intonation : montée légère à la fin de la proposition en if, puis descente sur le résultat : « If I'd taken the job ↗, I'd be rich now ↘ ».
  • On accentue les mots qui portent le contraste : « If I'd STAYED, I'd be MANager now. »

En situation

Listening Studio

À Toronto, deux amis, Jérôme (originaire de Lille) et Fatou (originaire de Thiès), discutent dans un café de leurs choix de vie.

Fatou

Do you ever think about what your life would be like if you hadn't moved here?
Tu te demandes parfois à quoi ressemblerait ta vie si tu n'avais pas déménagé ici ?

Jérôme

All the time. If I had stayed in Lille, I would probably be working in my father's shop now.
Tout le temps. Si j'étais resté à Lille, je travaillerais sûrement dans la boutique de mon père aujourd'hui.

Fatou

And you wouldn't speak English so well!
Et tu ne parlerais pas aussi bien anglais !

Jérôme

True. What about you? If you hadn't got that scholarship, would you still be in Senegal?
C'est vrai. Et toi ? Si tu n'avais pas obtenu cette bourse, tu serais encore au Sénégal ?

Fatou

I think so. But honestly, if I weren't so stubborn, I would have given up after the first winter.
Je pense. Mais honnêtement, si je n'étais pas aussi têtue, j'aurais abandonné après le premier hiver.

Jérôme

Ha! If you weren't stubborn, you wouldn't have finished your PhD either.
Ha ! Si tu n'étais pas têtue, tu n'aurais pas fini ton doctorat non plus.

Fatou

Exactly. And if we hadn't met at that conference, we wouldn't be sitting here today.
Exactement. Et si on ne s'était pas rencontrés à ce congrès, on ne serait pas assis ici aujourd'hui.

Jérôme

So no regrets, then. Another coffee?
Donc pas de regrets. Un autre café ?

Exercices

Writing Workshop

Du plus simple au plus difficile. Réponds sans regarder la leçon, puis vérifie chaque exercice.

1. Analyser le temps

Pour chaque phrase, dis si la condition et le résultat concernent le passé ou le présent.

  1. If I had saved more money, I would be on holiday now.
  2. If he were more patient, he wouldn't have shouted at the kids.
  3. If you had told me, I would have helped.
  4. If I had more time, I would learn Spanish.
Voir le corrigé
  1. Condition passée, résultat présent (mixte A).
  2. Condition présente, résultat passé (mixte B).
  3. Condition passée, résultat passé (3e conditionnel).
  4. Condition présente, résultat présent (2e conditionnel).

2. Compléter

Mets le verbe entre parenthèses à la forme qui convient.

  1. If I ___ (not / miss) the bus, I would be at work now.
  2. If she ___ (be) less shy, she would have asked for a pay rise.
  3. We ___ (not / be) lost now if we had brought a map.
  4. If they ___ (speak) English, they would have understood the guide.
  5. If you had gone to bed earlier, you ___ (not / feel) so tired now.
  6. If I didn't love my job, I ___ (leave) years ago.
Voir le corrigé
  1. hadn't missed
  2. were (ou was)
  3. wouldn't be
  4. spoke
  5. wouldn't feel (ou wouldn't be feeling)
  6. would have left

3. Combiner

Fais une seule phrase avec un conditionnel mixte.

  1. I didn't learn to drive. Now I can't get a job as a delivery driver.
  2. He's very lazy. He didn't finish the project.
  3. We didn't buy the house in 2015. We aren't rich now.
  4. I don't speak Dutch. I didn't understand the announcement.
  5. She accepted the job in Montreal. She lives in Canada now.
Voir le corrigé
  1. If I had learnt (learned) to drive, I could get a job as a delivery driver now.
  2. If he weren't (wasn't) so lazy, he would have finished the project.
  3. If we had bought the house in 2015, we would be rich now.
  4. If I spoke Dutch, I would have understood the announcement.
  5. If she hadn't accepted the job in Montreal, she wouldn't live (wouldn't be living) in Canada now.

4. Corriger les erreurs

Chaque phrase contient une erreur. Réécris-la correctement.

  1. If I would have known, I would be there now.
  2. If I had studied law, I would have been a lawyer now.
  3. If I didn't lose my phone yesterday, I could call her now.
  4. If she isn't so stubborn, she would have apologised.
Voir le corrigé
  1. If I had known, I would be there now.
  2. If I had studied law, I would be a lawyer now.
  3. If I hadn't lost my phone yesterday, I could call her now.
  4. If she weren't (wasn't) so stubborn, she would have apologised.

5. Traduire

Traduis en anglais.

  1. Si j'avais pris ce poste, je vivrais à Bruxelles maintenant.
  2. S'il était plus prudent, il n'aurait pas eu cet accident.
  3. Si nous n'avions pas raté l'avion, nous serions à Dakar en ce moment.
  4. Si tu parlais allemand, tu aurais obtenu le poste.
Voir le corrigé
  1. If I had taken that job, I would live (would be living) in Brussels now.
  2. If he were (was) more careful, he wouldn't have had that accident.
  3. If we hadn't missed the plane, we would be in Dakar now (at the moment).
  4. If you spoke German, you would have got the job.

6. À toi

Pense à une décision importante de ta vie et à un trait de ton caractère. Écris 4 phrases : deux avec « passé → présent » et deux avec « présent → passé ».

  1. Exemple de réponse
Voir le corrigé
  1. If I hadn't started learning English, I wouldn't be able to work with clients in Canada now. If I had chosen to study engineering, I might be earning more today. If I weren't so impatient, I would have finished my first novel. If I were more organised, I wouldn't have missed so many deadlines last year.
À retenir
  • Condition passée → résultat présent : If + past perfect, would / could / might + base (If I had left, I would be there now).
  • Condition présente (permanente) → résultat passé : If + prétérit, would have + participe (If I were braver, I would have asked).
  • Posez la question : quand se situe la condition ? quand se situe le résultat ?
  • Jamais « would » après if ; « now / today » dans le résultat → would + base.
  • Formes progressives possibles : wouldn't be feeling, would be living.
