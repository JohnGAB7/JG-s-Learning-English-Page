The first conditional

The first conditional (If it rains, I'll stay at home) talks about a possible, realistic future situation and its likely result. We use it all the time to warn, negotiate, promise and make plans.

⏱ 30–45 min✎ Written by JG◎ Level B1

Prefer explanations in French? Version française de cette leçon →

By the end of this lesson, you will be able to:
  • Build a first conditional sentence with if + present simple and will + base verb.
  • Never put will in the if-clause.
  • Vary the result with may, might, can, should, be going to or an imperative.
  • Tell the difference between if and when, and use unless in simple cases.

The structure

There are two parts: the condition (if + present simple) and the result (will / won't + base verb). The order is free. If the sentence starts with if, put a comma between the two parts; if it starts with the result, no comma.

The present simple in the if-clause really talks about the future. Learners often add will “to match”, but it is wrong.

Condition (if + present)Result (will + base verb)
If it rains tomorrow,we'll stay at home.
If you don't hurry,you'll miss the bus.
If she gets the job,she'll move to Toronto.
If they don't call,I won't wait for them.
  • We'll stay at home if it rains tomorrow.
    Result first: no comma.
  • If you study regularly, you'll pass the exam.
    A realistic situation and a likely result.

Questions and negatives

The question is usually about the result: What will you do if…? / Will you come if…? A negative can be in either part, or in both.

After if, we often use any, anyone, anything in an affirmative sentence: “If anyone calls, take a message.”

  • What will you do if you don't get a visa?
    Question about the result.
  • Will you come if I invite Paul?
    Yes/no question.
  • If you don't call me, I won't know where you are.
    Negatives in both parts.

Varying the result

The result isn't always will. Use a modal to change the meaning: may / might (perhaps), can (possibility, permission), should (advice), must (obligation), be going to.

The result can also be an imperative, very common for instructions: “If you see Anna, tell her to call me.”

ResultExampleMeaning
might / mayIf we leave now, we might catch the train.possible, not sure
canIf you finish early, you can go home.permission / possibility
shouldIf you feel ill, you should see a doctor.advice
mustIf you want to apply, you must register first.obligation
imperativeIf it's too hot, open the window.instruction

If or when? Unless?

If = it isn't certain that it will happen. When = we know it will happen; only the time is open. “If I see him, I'll tell him” (I may not see him) / “When I see him, I'll tell him” (I'm seeing him tomorrow at work). In both cases: present simple, not will.

Unless = if… not: “You won't pass unless you study” = “You won't pass if you don't study.” Unless is followed by an affirmative verb. Lesson 100 looks at unless, as long as and provided that in detail.

  • When I get to Yaoundé, I'll call you.
    I'm sure I'll get there.
  • If I get the scholarship, I'll study in Montreal.
    Not sure I'll get it.
  • We'll go to the beach unless it rains.
    Except if it rains.

Real-life uses

We use the first conditional to warn (If you touch that, you'll burn yourself), threaten (If you're late again, you'll lose your job), promise or negotiate (If you help me, I'll buy you lunch) and persuade (If you buy two, you'll get one free).

In very polite or formal English, you may meet “If you will…” (if you are willing to) or “If you should need anything…”: these are special cases, not exceptions to the main rule.

  • If you help me move, I'll cook you dinner.
    Negotiating.
  • If you press this button, the machine will stop.
    Instructions for a machine.

The formula

If + present simple, will / won't + base verb (If it rains, I'll stay at home.)

Pronunciation

Pronunciation Lab

  • The voice rises at the end of the if-clause and falls at the end of the result: “If it RAINS ↗, we'll stay at HOME ↘.” The pause matches the comma.
  • 'll is very light but must be heard: “I'll call” /aɪl kɔːl/, “we'll go” /wiːl ɡəʊ/. Without it, the sentence is wrong.
  • won't /wəʊnt/ is often stressed: “I WON'T wait.”
  • if is /ɪf/ with a short i, as in “it”, never /iːf/.
  • unless /ənˈles/: stress on the second syllable.

Common mistakes

Don’t saySayWhy
✗ If it will rain, we'll stay at home.✓ If it rains, we'll stay at home.No will in the if-clause.
✗ When I will arrive, I'll call you.✓ When I arrive, I'll call you.Same rule after when, as soon as, before, until.
✗ If you will study, you pass.✓ If you study, you'll pass.The tenses are swapped: present after if, will in the result.
✗ Unless you don't hurry, you'll be late.✓ Unless you hurry, you'll be late.Unless already contains the negative (= if not).
✗ If I see him I tell him.✓ If I see him, I'll tell him.A future result needs will (and a comma after the if-clause).
✗ If she'll come, we'll start.✓ If she comes, we'll start.'ll = will: not allowed in the condition.

In a conversation

Listening Studio

Namur, in a small bakery. Lucie, the owner, prepares for a busy weekend with Youssef, her new employee.

Lucie

If it's sunny on Saturday, we'll have a lot of customers.
If + present, will + verb.

Youssef

What will we do if we run out of bread?
Question about the result.

Lucie

If that happens, call me and I'll bake more.
Imperative + will in the result.

Youssef

OK. And if I finish early, can I leave at four?
Result with can (permission).

Lucie

Yes, unless the shop is still full.
Unless = if… not.

Youssef

Fair enough. If you show me the new oven, I'll start it myself next time.
A small deal.

Lucie

Good idea. When we close tonight, I'll show you.
When: it will certainly happen.

Youssef

Perfect. If it goes well, you might get a day off!
Might = maybe.

Exercises

Writing Workshop

From easy to harder. Answer without looking at the lesson, then check each exercise.

1. Match

Choose the logical ending: a) you'll get wet. b) I'll lend you some. c) she'll be angry. d) we'll miss the start.

  1. If you need money, …
  2. If we don't leave now, …
  3. If you go out without an umbrella, …
  4. If you forget her birthday, …
Show the answers
  1. b) I'll lend you some.
  2. d) we'll miss the start.
  3. a) you'll get wet.
  4. c) she'll be angry.

2. Put the verbs in the right form

Complete with the correct forms (first conditional).

  1. If you ___ (leave) the ice cream in the sun, it ___ (melt).
  2. If she ___ (not / come), we ___ (start) without her.
  3. What ___ you ___ (do) if the flight is cancelled?
  4. I ___ (not / go) if Marc ___ (be) there.
  5. If they ___ (offer) me the job, I ___ (accept) it.
Show the answers
  1. leave … 'll melt (will melt)
  2. doesn't come … 'll start (will start)
  3. will … do
  4. won't go … is
  5. offer … 'll accept (will accept)

3. If, when or unless?

Complete with if, when or unless.

  1. I'll phone you ___ I get to the hotel tonight.
  2. You'll fail the test ___ you revise.
  3. ___ it's too expensive, we won't buy it.
  4. We'll eat outside ___ it's cold.
Show the answers
  1. when
  2. unless
  3. If
  4. unless

4. Correct the mistakes

Each sentence has one mistake. Write it correctly.

  1. If I will see her, I'll give her the book.
  2. Unless you don't stop, I'll call the police.
  3. If you'll be late, call me.
  4. We go to the park if it's sunny tomorrow.
Show the answers
  1. If I see her, I'll give her the book.
  2. Unless you stop, I'll call the police. / If you don't stop, I'll call the police.
  3. If you're late, call me.
  4. We'll go to the park if it's sunny tomorrow.

5. Make conditional sentences

Write one first conditional sentence from the prompts.

  1. rain tomorrow / we / stay at home
  2. you / need help / call me (imperative)
  3. when / I / arrive in Montreal / send you a message
  4. we / leave now / might / arrive on time
Show the answers
  1. If it rains tomorrow, we'll stay at home.
  2. If you need help, call me.
  3. When I arrive in Montreal, I'll send you a message.
  4. If we leave now, we might arrive on time.

6. Your turn

Write 4 first conditional sentences about next week: one with will, one with might, one with an imperative and one with unless.

  1. Example answer
Show the answers
  1. If I finish work early on Friday, I'll go to the cinema. If the weather is good, we might have a barbecue. If you're free on Sunday, come and have lunch with us. I won't go to the gym unless my friend comes with me.
Key points
  • If + present simple, will + base verb: a possible, realistic future situation.
  • Never will in the if-clause (or after when, as soon as, until, before).
  • Comma when the sentence starts with if; no comma in the other order.
  • The result can use might, can, should, must or an imperative.
  • If = not sure; when = sure; unless = if… not.
