Some and any

“Some” and “any” talk about a quantity that is not exact. The basic rule is simple (some in positive sentences, any in negatives and questions), but you also need the exceptions for offers and polite requests.

⏱ 30–45 min✎ Written by JG◎ Level A1

Prefer explanations in French? Version française de cette leçon →

By the end of this lesson, you will be able to:
  • Use some in positive sentences and any in negative sentences and questions.
  • Choose between a / an and some, depending on whether the noun is singular, plural or uncountable.
  • Use some in questions to offer or ask for something (Would you like some tea?).
  • Use some and any alone, as pronouns (I haven't got any).

The basic rule

Use “some” and “any” before a plural countable noun (eggs, apples) or an uncountable noun (milk, money). They show a quantity that we don't say exactly.

Use “some” in positive sentences, and “any” in negative sentences and questions.

Sentence typePlural countableUncountable
PositiveThere are some eggs.There's some milk.
NegativeThere aren't any eggs.There isn't any milk.
QuestionAre there any eggs?Is there any milk?
  • I've got some friends in Montreal.
    Positive: some.
  • We haven't got any bread.
    Negative: any.
  • Have you got any questions?
    Question: any.

A / an or some? And when do we use nothing?

With a singular countable noun, use “a” or “an”: “an apple”, “a banana”. “Some” and “any” are for plurals and uncountable nouns: “some apples”, “some water”.

When you talk about something in general, use no word: “I like coffee” (coffee in general). When you talk about an amount, use “some”: “I'd like some coffee” (a cup, a quantity).

“Some” is not always necessary: “We need eggs” and “We need some eggs” are both correct.

NounPositiveNegative / question
singular countablea / an: an egga / an: I haven't got an egg.
plural countablesome: some eggsany: any eggs
uncountablesome: some riceany: any rice
  • There's an orange and some grapes on the table.
    an + singular; some + plural.
  • I love chocolate. Can I have some?
    General: no word. An amount: some.

Exceptions: some in questions

When you offer something or make a polite request, use “some” even in a question, because you expect the answer “yes”.

Compare: “Is there any coffee?” (a real question: is there coffee or not?) and “Would you like some coffee?” (an offer).

  • Would you like some tea?
    An offer.
  • Can I have some water, please?
    A request.
  • Could you give me some information about the course?
    A polite request.
“Any” in a positive sentence has another meaning: “it doesn't matter which”. “Take any seat” = sit where you want.

Not any = no

You can replace “not … any” with “no” + noun and a positive verb: “There isn't any milk” = “There's no milk”. “No” is a little stronger.

Never use two negatives: “I haven't got no money” is wrong in standard English. Say “I haven't got any money” or “I've got no money”.

  • There aren't any buses on Sunday. = There are no buses on Sunday.
    Two ways to say the same thing.
  • I've got no time today.
    no + noun, positive verb.

Some and any alone (pronouns)

When we already know the noun, we can use “some” and “any” alone: “I need eggs. Have you got any? — Yes, I've got some.”

Careful: don't put “of” between some / any and a noun: “some bread”, not “some of bread”. Use “some of” only before the, my, these…: “some of my friends”.

Words like something, anything, someone, nobody follow the same logic: see lesson 60.

  • I want some cake. Is there any left? — Sorry, there isn't any.
    any alone = any cake.
  • Some of my friends speak Spanish.
    some of + my + noun.

The formula

some + plural / uncountable (positive, offers, requests) · any + plural / uncountable (negatives, questions)

Pronunciation

Pronunciation Lab

  • Before a noun, “some” is weak: “some water” = /səm ˈwɔːtə/. Alone or at the end of a sentence, it is strong: “Yes, I've got some” = /sʌm/.
  • “any” is /ˈeni/ (“enny”). “many” and “any” rhyme.
  • Link before a vowel: “any eggs” = /ˌeni ˈeɡz/; “some apples” = /səm ˈæplz/.
  • In an offer, the voice goes up at the end: “Would you like some TEA? ↗”.

In a conversation

Listening Studio

In Liège, Thomas and his flatmate Aminata want to make pancakes for some friends.

Aminata

Let's make pancakes! Have we got any flour?
Question: any.

Thomas

Yes, there's some flour in the cupboard.
Positive: some.

Aminata

Great. And are there any eggs?
Plural countable: any.

Thomas

Hmm, no, there aren't any eggs. And there's no milk.
not any = no.

Aminata

OK, let's write a shopping list: eggs, milk and some sugar.
A list.

Thomas

We've got some sugar. But we haven't got any butter.
Positive and negative.

Aminata

Right: eggs, milk, butter. Do we need any juice for our friends?
A real question: any.

Thomas

Yes, let's get some orange juice. And would you like some coffee before we go?
An offer: some.

Aminata

No, thanks. Let's go!
Saying no politely.

Key points
  • some + plural or uncountable in positive sentences; any in negatives and questions.
  • a / an before a singular countable noun; no word when you talk in general (I like coffee).
  • Offers and requests: some in the question (Would you like some tea? Can I have some water?).
  • not any = no; never two negatives (I haven't got any money / I've got no money).
  • some and any can stand alone (Have you got any? — Yes, I've got some).
