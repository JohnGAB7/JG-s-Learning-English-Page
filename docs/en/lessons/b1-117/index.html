So and such

“So” and “such” make an adjective or a noun stronger: “It was so hot!”, “It was such a hot day!”. They also express a result with “that”: “so tired that I fell asleep”. The rule is simple, but the two words are often confused.

⏱ 30–45 min✎ Written by JG◎ Level B1

Prefer explanations in French? Version française de cette leçon →

By the end of this lesson, you will be able to:
  • Use so + adjective / adverb and such (a / an) + (adjective) + noun.
  • Choose between so many / so much / so few / so little and such a lot of.
  • Express a result with so … that and such … that.
  • Tell so / such apart from very and avoid “so a” or “such beautiful”.

So + adjective or adverb

“So” goes before an adjective on its own (with no noun after it) or before an adverb. It is more expressive than “very”: it often shows an emotion or reaction (surprise, admiration, annoyance).

The difference from very: “very” just gives information (“The film was very long”); “so” adds emotion or leads to a result (“The film was so long! I nearly fell asleep”).

  • The view from Mount Cameroon is so beautiful!
    so + adjective: emotion.
  • You speak so quickly — I can't follow you.
    so + adverb.
  • I'm so happy you came!
    so + adjective.

Such + (a / an) + adjective + noun

“Such” goes before a noun phrase. With a singular countable noun, put “a / an” AFTER such: such a + (adjective) + noun. With a plural or uncountable noun, there is no article: such + (adjective) + noun.

Remember: “so + adjective” when the adjective is alone; “such + noun” as soon as there is a noun.

PatternExampleNote
so + adjectiveThe day was so hot.no noun
such a + adjective + singular nounIt was such a hot day.a after such
such + adjective + plural nounThey are such kind people.no article
such + adjective + uncountable nounWe had such good weather.no article
such a + noun (no adjective)He's such a liar!a strong opinion

So many, so much, such a lot of

Before a quantity, use so + many / much / few / little: so many people (countable), so much traffic (uncountable), so few chairs, so little time.

“Such a lot of” is the informal equivalent for both kinds of noun: such a lot of work, such a lot of problems. Don't say “such many” or “so a lot of”.

  • There were so many people at the concert in Abidjan!
    so many + plural.
  • I have so much work this week.
    so much + uncountable.
  • We had such a lot of fun at the wedding.
    such a lot of + uncountable.

Result: so … that / such … that

Add “that” + a clause to show the result. In speech, “that” is often left out: “I was so tired I fell asleep on the bus.”

The same patterns apply: so + adjective / adverb / quantity + that; such (a) + noun + that.

  • The exam was so difficult that half the class failed.
    so + adjective + that.
  • It was such a good film that I watched it twice.
    such a + adjective + noun + that.
  • She drove so fast that she got a fine.
    so + adverb + that.
  • There was so much noise that we couldn't talk.
    so much + noun + that.

Other uses and register

“So” is very common in speech, especially for emotions: “I'm so sorry”, “Thank you so much”, “It's so nice to see you”. In formal writing, people often prefer extremely, very, particularly.

“Such” can also mean “of this kind, like that”: “I've never seen such a thing”; “such as” = “for example, like”: “fruit such as mangoes and papayas”.

In a question you can say “Why are you so angry?”; for an exclamation you can also use “how”: “How beautiful!” = “It's so beautiful!”.

  • Thank you so much for your help.
    A very common spoken phrase.
  • The shop sells tropical fruit such as mangoes and pineapples.
    such as = for example.

The formula

so + adjective / adverb · such (a / an) + (adjective) + noun · so many / much + noun · … (that) + result

Pronunciation

Pronunciation Lab

  • “so” is often lengthened and stressed for emotion: It was SOOO good! /səʊ/ (UK).
  • “such” is /sʌtʃ/: a short u as in “cup”, and /tʃ/ at the end as in “match”.
  • In “such a”, the words link: /ˈsʌtʃ ə/, almost “sutcha”.
  • In “so … that”, “that” is weak: /ðət/; the stress is on so and the adjective: so TIRED that…

Don’t saySayWhy

✗ They are so nice people.✓ They are such nice people.Adjective + plural noun: such.
✗ She's such kind.✓ She's so kind.Adjective alone: so.
✗ It was a such good idea.✓ It was such a good idea.The article goes after such.
✗ There were such many cars.✓ There were so many cars.Quantity: so many / so much.
✗ I was so tired as I fell asleep.✓ I was so tired (that) I fell asleep.The result is introduced by that (or nothing).

In a conversation

Listening Studio

Kevin is back from a weekend at the Montreal jazz festival and tells his colleague Aïcha about it.

Aïcha

So, how was the jazz festival?
Here “so” just starts the conversation.

Kevin

Amazing! There were so many people that we could hardly move.
so many … that.

Aïcha

And the music?
A short question.

Kevin

It was such good music. The last band was so talented that everyone was dancing.
such + uncountable; so + adjective + that.

Aïcha

Lucky you! Was the weather OK?
A common reaction.

Kevin

We had such a hot weekend — 32 degrees! And the concerts finished so late.
such a + adjective + noun; so + adverb.

Aïcha

You must be so tired.
so + adjective.

Kevin

I am! I had such a lot of fun, but I need a holiday after my holiday!
such a lot of.

Exercises

Writing Workshop

From easy to harder. Answer without looking at the lesson, then check each exercise.

1. So or such?

Complete with so or such (a / an if needed).

  1. The soup is ___ hot that I can't eat it.
  2. It was ___ interesting book.
  3. They are ___ friendly neighbours.
  4. Why are you ___ angry?
  5. We had ___ bad luck on our trip.
  6. He runs ___ fast!
  7. It's ___ beautiful city.
Show the answers
  1. so
  2. such an
  3. such
  4. so
  5. such
  6. so
  7. such a

2. So many, so much, such a lot of

Complete with so many, so much or such a lot of (sometimes two answers).

  1. There's ___ traffic in Lagos.
  2. I've got ___ emails to answer.
  3. She spent ___ money on clothes.
  4. There were ___ mistakes in the report.
Show the answers
  1. so much / such a lot of
  2. so many / such a lot of
  3. so much / such a lot of
  4. so many / such a lot of

3. Join with so / such … that

Join the two sentences with so … that or such … that.

  1. The film was boring. I fell asleep.
  2. It was a long queue. We left.
  3. She was nervous. She couldn't speak.
  4. They are good friends. They talk every day.
Show the answers
  1. The film was so boring that I fell asleep.
  2. It was such a long queue that we left.
  3. She was so nervous that she couldn't speak.
  4. They are such good friends that they talk every day.

4. Correct the mistake

Each sentence has one mistake. Write it correctly.

  1. It was so a nice evening.
  2. He's such rude!
  3. We had such a terrible weather.
  4. There were such many people.
Show the answers
  1. It was such a nice evening.
  2. He's so rude!
  3. We had such terrible weather.
  4. There were so many people.

5. Rewrite

Rewrite with the word in brackets. Keep the same meaning.

  1. The house is so pretty! (such)
  2. I was very tired, so I went home early. (so … that)
  3. There was a lot of noise — too much! (so much)
Show the answers
  1. It's such a pretty house!
  2. I was so tired that I went home early.
  3. There was so much noise!

6. Your turn

Describe a memorable event (party, trip, concert, match) in five sentences with so, such and at least two results with that.

  1. Model answer
Show the answers
  1. Last year I went to my cousin's wedding in Bafoussam. It was such a big wedding — there were more than 500 guests! The food was so delicious that I ate three plates. The music was so loud that I couldn't hear my phone. It was such a wonderful day.
Key points
  • so + adjective / adverb alone (so hot, so quickly).
  • such + (a / an) + (adjective) + noun (such a hot day, such kind people, such good weather).
  • so many / so much / so few / so little + noun; such a lot of + noun.
  • Result: so / such … (that) + clause.
  • Never “so a” or “a such”; no a with uncountable nouns (such good weather).
