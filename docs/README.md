# Site content model

The public-facing website is generated from static files under this directory.

## URLs
- / — landing page
- /parcours/ — CEFR level roadmap
- /lecons/ — searchable lesson library
- /lecons/{level}-{number}/ — canonical lesson page
- /actualites/ — world and country-filtered news
- /apropos/ — project and learning method

## Content publication states
Use these editorial states in source records and review:
- draft
- needs-source
- reviewed
- published

Only reviewed and published content may be shown as complete to learners. Placeholders must remain clearly labeled.
